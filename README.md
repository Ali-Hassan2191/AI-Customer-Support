# Customer Support AI Agent

Beginner-friendly customer support demo built with Streamlit + one CrewAI agent + Gemini.

## Repository files

Keep these files in the repository root:

- `app.py`
- `agent.py`
- `tools.py`
- `escalation.py`
- `requirements.txt`
- `orders.xlsx`
- `faiss.index`
- `chunks.json`

`faiss.index` and `chunks.json` must be the matching pair generated by your existing embedding pipeline. The configured embedding model is `sentence-transformers/all-MiniLM-L6-v2` (384 dimensions).

## Streamlit Cloud secrets

In Streamlit Cloud, open your app's **Settings → Secrets** and add:

```toml
GEMINI_API_KEY = "your-Google-Gemini-API-key"
GEMINI_MODEL = "gemini/gemini-3.5-flash-lite"
```

Change `GEMINI_MODEL` to the exact Gemini model identifier enabled for your API key. The code uses CrewAI's LiteLLM provider naming (`gemini/<model-id>`). If your provider dashboard lists a newer Flash-Lite model, use that exact ID here. Do not commit API keys to GitHub.

`GOOGLE_API_KEY` is also accepted as an alternative to `GEMINI_API_KEY`.

## Deploy

1. Upload the files above to a GitHub repository.
2. Ensure `orders.xlsx`, `faiss.index`, and `chunks.json` are in the repository root.
3. In Streamlit Community Cloud, create an app from that repository.
4. Set the main file path to `app.py`.
5. Add the secrets shown above and deploy.

No local run is required for this deployment flow.

## How it works

- **Company knowledge tool:** embeds the question using `all-MiniLM-L6-v2`, searches FAISS, and returns matching text plus source/page metadata.
- **Order tool:** looks up the Excel file and requires both order ID and the matching contact number before returning order status.
- **Escalation tool:** creates a pending ticket with a short summary in `pending_tickets.csv`.
- **Session memory:** Streamlit `session_state` stores chat turns for the current browser session; recent turns are passed into the agent prompt.

## Important demo limitations

- The Excel file is read-only; the agent cannot actually cancel, edit, refund, or update orders.
- Ticket CSV storage on Streamlit Cloud is temporary and can be lost when the app restarts/redeploys. For reliable production tickets, connect a persistent database or ticketing service.
- Avoid committing real customer data to a public repository. Use a private repository and synthetic/test data for demos.
- The order lookup deliberately does not reveal the saved phone number or full shipping address.
- If `chunks.json` uses an unusual structure, update `_get_chunk_text()` / `_load_chunks()` in `tools.py` to match its keys.
